# Aman Obaid — Portfolio

Personal portfolio and engineering showcase for **Aman Obaid** (AI Backend Engineer & GenAI Systems Developer).

---

## ⚡ Overview

This repository hosts the personal portfolio showcasing production AI systems, LLM orchestration workflows, RAG pipelines, and backend architectures. It features:

- **Minimalist Engineering Design**: Refined dark-mode interface with zero distracting gradients, high typography contrast, and Bento-grid layouts.
- **Ava AI Chatbot**: An interactive personal assistant widget integrated with a live RAG backend (`https://personalaibot-1.onrender.com/query`) to answer queries about projects, experience, and skills.
- **Projects & Capabilities Showcase**: Detailed highlights of production systems (DocuScope, AgenticBlogger, GrabPic, and Lynn Concierge at Pinch Lifestyle) and categorized technical skill groups.
- **Frontend Architecture**: Modern **Vue 3** web application (`Frontend/`) with responsive Bento grids and zero bright gradients.

---

## 🛠️ Tech Stack

### Web Application (`Frontend/`)
- **Framework**: [Vue 3](https://vuejs.org/) + [Vite](https://vitejs.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide Vue Next](https://lucide.dev/)
- **Utilities**: [@vueuse/core](https://vueuse.org/)

---

## 🚀 Getting Started

### Running the Vue 3 Frontend (Recommended)

```bash
cd Frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

To create an optimized production build:
```bash
npm run build
npm run preview
```
